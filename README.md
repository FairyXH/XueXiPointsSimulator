# 学习强国积分模拟器

一个基于 HTML 的学习强国积分页面模拟工具，可自定义页面展示信息、查看积分明细，并将当前页面导出为 PNG 图片。支持桌面和移动端浏览器，页面数据仅用于模拟展示，不会修改真实账户积分。

## 使用方法

1. 打开 GitHub Pages 网站，或下载项目中的 `index.html`，使用浏览器打开。
2. 在**积分中心**页面点击左上角的返回箭头，即可打开或收起悬浮控制面板。
3. 在面板中修改昵称、头像文字、星级、点点通、年度积分等信息。星级输入 1–10，段位名称和星星数量会自动变化。
4. 选择一个**基准日期**，填写该日期的**成长总积分**。页面会按每天增加 44 分计算至浏览器当前日期，并更新展示的成长总积分。年度积分可以单独设置。
5. 点击积分中心右上角的 `···` 进入**积分明细**；明细页左上角箭头用于返回积分中心。可以通过控制面板中的时间选择器调整明细首条记录的时间，其余记录按原时间间隔同步调整。
6. 在控制面板中选择图片导出尺寸，点击**下载当前页面 PNG**。导出的是当前显示的积分中心或积分明细页面，不包含控制面板；图片从页面顶部开始截取。若微信内置浏览器不支持直接下载，可打开导出的图片后长按保存。

设置会保存在当前浏览器本地。清除浏览器站点数据或更换设备后，可能需要重新填写。

## 部署到 GitHub Pages

将 HTML 文件命名为 `index.html` 并放在仓库根目录，在仓库 **Settings → Pages** 中选择从 `main` 分支的根目录（`/root`）部署。等待发布完成后，打开 GitHub Pages 提供的网址即可使用。

> 说明：本项目为非官方的积分界面模拟器，仅供界面展示、设计与测试使用，与学习强国官方无关。所有展示数据均为模拟数据。
